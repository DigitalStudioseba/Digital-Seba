================================================================================
IMPORTANT RULES
================================================================================

1. Each folder starts with ## followed by the folder name
2. Bilingual names use format: English Name / বাংলা নাম
3. Each file on its own line: File Name URL
4. No empty lines between files in same folder
5. One empty line between folders
6. URLs must be valid Google Drive links
7. File names should be descriptive
8. No special characters in file names (except spaces and dashes)

================================================================================
SUPPORTED URL TYPES
================================================================================

✅ Google Drive Files:
https://drive.google.com/file/d/FILE_ID/view
https://drive.google.com/file/d/FILE_ID/view?usp=sharing

✅ Google Docs:
https://docs.google.com/document/d/DOC_ID/edit

✅ Google Sheets:
https://docs.google.com/spreadsheets/d/SHEET_ID/edit

✅ Google Slides:
https://docs.google.com/presentation/d/SLIDES_ID/edit

✅ Google Drive Folders (will be listed as single item):
https://drive.google.com/folders/FOLDER_ID

❌ NOT Supported:
- Non-Google Drive URLs
- Shortened URLs (bit.ly, etc.)
- Private/restricted links (make public or anyone with link)

================================================================================
FILE TYPE DETECTION
================================================================================

The system automatically detects file types from:
- File extension in name (.pdf, .doc, .zip, etc.)
- Google Drive URL patterns
- Document type (Docs, Sheets, Slides)

Common types:
PDF, DOC, DOCX, SHEET, SLIDES, VIDEO, IMAGE, ZIP, FILE

================================================================================
TESTING YOUR DATA
================================================================================

1. Copy your formatted data
2. Visit /admin in your browser
3. Paste into the text area
4. Click "Auto Convert Format" if needed
5. Click "Parse & Validate"
6. Check results:
   - ✅ No duplicates
   - ✅ No invalid URLs
   - ✅ All folders listed
   - ✅ File counts correct
7. Click "Copy Code"
8. Paste into src/data/resources-data.ts
9. Save and refresh /resources

================================================================================
TIPS FOR SUCCESS
================================================================================

✓ Make all Google Drive files "Anyone with link can view"
✓ Use descriptive file names (not "Document1", "File2")
✓ Group related content in folders
✓ Keep folder names short but meaningful
✓ Add Bengali translations for local users
✓ Test each link before adding
✓ Remove any duplicate URLs
✓ Use consistent naming conventions

================================================================================
COMMON MISTAKES TO AVOID
================================================================================

✗ Forgetting ## before folder names
✗ Using special characters like | or " in names
✗ Adding extra spaces before/after URLs
✗ Using private/restricted Google Drive links
✗ Mixing different formats in one file
✗ Forgetting to add file names before URLs
✗ Using shortened URLs instead of full Drive links
